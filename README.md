# PVBench project website

Static project page for **PVBench: Quantifying Physical Plausibility in Video Generation with Object-Level Physical Measurements**.

## Preview locally

Open `index.html` directly, or serve this folder with any static HTTP server. The site has no build step and is suitable for GitHub Pages.

## Teaser video

The landing page uses a full-screen, pinned video stage inspired by contemporary computer-vision project pages. The current private preview uses `assets/pvbench-teaser.mp4`; replace it with the approved teaser before public launch. `assets/teaser-poster.svg` remains optional original project artwork; the video stage now loads without a poster so the first visible frame is the actual video.
