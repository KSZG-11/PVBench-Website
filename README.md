# PVBench project website

Static project page for **PVBench: Quantifying Physical Plausibility in Video Generation with Object-Level Physical Measurements**.

## Preview locally

Open `index.html` directly, or serve this folder with any static HTTP server. The site has no build step and is suitable for GitHub Pages.

## Included sections

- Full-screen teaser video and paper overview
- Seven-domain taxonomy and data-curation figures
- Paper evaluation results and leaderboard
- Interactive T2V/I2V comparison across 25 physical dimensions and five models
- Citation and release links

The website repository contains the presentation assets required by the static page and follows the project release policy.
